LayerNorm

The LayerNorm forward pass, with one program per row. Unlike the softmax, the row doesn't have to fit in one tile: the kernel loops over it in blocks.

What it computes

layernorm(x, w, b, eps=1e-5) normalizes each row of a 2D NumPy array over its last dimension and returns (y, mean, rstd):

  • y is (x - mean) * rstd * w + b, in the input dtype.
  • mean and rstd hold the mean and the reciprocal standard deviation of each row, in float32.

How it works

The grid is (m,), one program per row. Each program first moves x_ptr and y_ptr to the start of its row, and then makes three passes over the row, BLOCK columns at a time:

  1. Sum the row into a float32 accumulator tile, and reduce it with tl.sum to get the mean.
  2. Sum the squared deviations to get the variance, and compute rstd = 1 / tl.sqrt(var + eps). tl.where(cols < n_cols, a - mean, 0.0) zeroes the masked lanes, which would otherwise contribute (0 - mean)².
  3. Normalize, scale by w, shift by b, and store y.

The kernel also stores mean and rstd for the row. The wrapper sets BLOCK to min(1024, next_power_of_2(n)) unless you pass block. The demo passes block=256, so each pass over the 1,000-column rows takes four iterations, and the last one is partly masked.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/03_layernorm.py

The demo normalizes a 32 by 1,000 float32 array and compares y with a NumPy reference computed in float64. The output is similar to the following:

max abs error: 9.536743e-07

The file's docstring runs the demo in the CPU interpreter, with ENCELADUS_INTERPRET=1. Both ways work, and they give errors of the same size. For more information, see Debugging.
