Flash attention

The flash attention forward pass, softmax(q @ kᵀ * sm_scale) @ v, with an optional causal mask. An online softmax means the full attention matrix never exists in memory.

What it computes

attention(q, k, v, causal=False) takes contiguous queries, keys, and values with the same shape, (batch, heads, seq_len, head_dim), and returns the attention output with that shape. The head dimension must be 16, 32, 64, or 128. sm_scale defaults to 1 / sqrt(head_dim). With causal=True, query i attends only to keys 0 to i.

How it works

Grid and descriptors

The grid is (cdiv(seq_len, block_m), batch * heads). Each program computes BLOCK_M query rows of one (batch, head) pair. tl.program_id(1) selects the pair, and the kernel offsets every base pointer by stride_h = seq_len * head_dim. Four tensor descriptors then cover that pair's (N_CTX, HEAD_DIM) slices of q, k, v, and the output.

Online softmax

The kernel loops over the keys in blocks of BLOCK_N. It keeps a running row maximum m_i, a running row sum l_i, and a float32 output accumulator acc. For each block, it does the following:

  1. Compute the scores with tl.dot(q, tl.trans(k_block)), scaled by qk_scale.
  2. Update the row maximum, and compute p = tl.exp2(qk - m_ij[:, None]).
  3. Rescale l_i and acc by alpha = tl.exp2(m_i - m_ij), the change in the maximum, and then add this block's contribution.

After the loop, the kernel divides acc by l_i and stores it. qk_scale folds log2(e) into sm_scale, so the kernel can use tl.exp2 instead of tl.exp.

Masks

  • The descriptor load zero-fills keys past N_CTX, which would give scores of 0. mask = cols[None, :] < N_CTX and tl.where replace those scores with -inf, so they get zero weight.
  • With CAUSAL, the mask also requires offs_m[:, None] >= cols[None, :], and the loop stops at hi = min((start_m + 1) * BLOCK_M, N_CTX), which skips key blocks that lie entirely above the diagonal.
  • CAUSAL is a constexpr, so Enceladus compiles a separate kernel for each value, and the untaken branch isn't compiled.

Registers and SIMD groups

  • q stays in registers across the loop, and tl.trans(k_desc.load(...)) loads k straight from device memory with transposed fragment loads.
  • The launch passes dot_warps=(num_warps, 1), so each SIMD group owns whole rows, block_m / num_warps of them. The row maximum and row sum then reduce inside each SIMD group.
  • p.to(q_desc.dtype) feeds the second tl.dot directly from the score registers.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/08_flash_attention.py

The demo runs attention on float16 inputs of shape (2, 3, 100, 64), without and with the causal mask. It compares each result with a NumPy reference computed in float64. The output is similar to the following:

max abs error, causal=False: 4.88e-04
max abs error, causal=True: 9.77e-04
