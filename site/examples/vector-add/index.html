Vector add

The smallest complete kernel: out = x + y. It shows the program ID, block offsets, and masks that every other example builds on.

What it computes

add(x, y) returns the elementwise sum of two contiguous arrays with the same shape and dtype. It accepts NumPy arrays, enceladus.Tensor objects, PyTorch tensors on the mps device, and MLX arrays. enceladus.new_empty(x) allocates the output with the same framework and device as x, so the result is the same kind of array that you pass in.

How it works

  • The grid is one-dimensional, with cdiv(n, block) programs. Each program handles BLOCK consecutive elements, 1,024 by default.
  • tl.program_id(0) returns the program's index, and pid * BLOCK + tl.arange(0, BLOCK) is the tile of element offsets that the program covers.
  • mask = offs < n keeps the last program in bounds. In the demo, n is 100,003, so the grid has 98 programs and the last one covers only 675 valid elements.
  • The wrapper flattens the array: n is the product of the shape, so any shape works as long as the array is contiguous.
  • BLOCK: tl.constexpr makes the block size a compile-time constant. Enceladus compiles one version of the kernel for each value you pass.

For more information about programs and tiles, see Programming model.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/01_vector_add.py

The demo adds two vectors of 100,003 random float32 values and compares the result with NumPy. If PyTorch is installed and the mps device is available, it repeats the add with PyTorch tensors and compares the result with tx + ty. The output is similar to the following:
