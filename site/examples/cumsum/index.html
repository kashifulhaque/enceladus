Cumulative sum

A row-wise cumulative sum with tl.cumsum. Each program scans a 2D tile that covers several whole rows.

What it computes

cumsum(x) returns the inclusive cumulative sum of each row of a 2D NumPy array. With reverse=True, it returns the suffix sum instead: each element is the sum of itself and every later element in its row. Integers narrower than 32 bits sum in int32, as in tl.cumsum.

How it works

  • Each program loads a BLOCK_M by BLOCK_N tile. BLOCK_N is next_power_of_2(n), so the tile covers BLOCK_M whole rows.
  • The wrapper sets BLOCK_M to max(1, min(16, 4096 // BLOCK_N)), which keeps the tile at 4,096 elements or fewer. For the demo's 1,000 columns, BLOCK_N is 1,024 and BLOCK_M is 4, so the grid has 75 programs for 300 rows.
  • The 2D mask guards both the last rows and the padding columns.
  • tl.cumsum(x, axis=1, reverse=REVERSE) scans along the rows. REVERSE is a constexpr, so the prefix and suffix sums compile to separate kernels.

For the scan builtins, see Scans in the language reference.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/10_cumsum.py

The demo computes the prefix sum of a 300 by 1,000 float32 array and compares it with np.cumsum in float32. Rounding differs between the GPU scan and NumPy's sequential sum, so the error is small but not zero. The output is similar to the following:

max abs error: 8.773804e-05
