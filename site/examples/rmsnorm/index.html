RMSNorm

The RMSNorm forward pass, x * rsqrt(mean(x²) + eps) * w, with one program per row and the whole row in one tile.

What it computes

rmsnorm(x, w, eps=1e-6) takes a 2D NumPy array x and a weight w with one value per column. It divides each row by its root mean square and multiplies by w, and returns the result in the input dtype.

How it works

  • The grid is (m,), one program per row, and BLOCK is next_power_of_2(n), so one tile holds the whole row, as in the row softmax.
  • Masked lanes load 0, so they add nothing to tl.sum(x * x, axis=0). The kernel divides by n_cols, not BLOCK, to get the mean.
  • tl.rsqrt computes the reciprocal square root in one call.
  • The wrapper passes the input and output row strides in elements, computed from the NumPy byte strides.

Compare this kernel with the LayerNorm example, which loops over the row in blocks instead of holding it in one tile.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/06_rmsnorm.py

The demo normalizes a 32 by 1,000 float32 array and compares the result with a NumPy reference computed in float64. The output is similar to the following:

max abs error: 9.536743e-07

The file's docstring runs the demo in the CPU interpreter, with ENCELADUS_INTERPRET=1. Both ways work, and they give errors of the same size. For more information, see Debugging.
