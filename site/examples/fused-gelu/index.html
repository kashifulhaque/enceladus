Fused GELU

A scale, a bias add, and a GELU in one kernel: gelu(x * scale + bias). Fusing the three operations reads and writes the data once instead of three times.

What it computes

fused_gelu(x, bias, scale) takes a contiguous 2D NumPy array x, a bias with one value per column, and a scalar scale. It returns gelu(x * scale + bias) in the input dtype, using the exact GELU, 0.5 * y * (1 + erf(y / sqrt(2))).

How it works

  • The kernel treats x as a flat array, like the vector add: the grid has cdiv(n, block) programs of BLOCK elements, and mask = offs < n guards the last one.
  • The bias is indexed with offs % n_cols, which maps each flat offset to its column. That's why x must be contiguous.
  • The math runs in float32. 0.7071067811865476 is 1 / sqrt(2), and tl.erf is the Gauss error function.
  • scale is an ordinary scalar argument, not a constexpr, so changing it doesn't recompile the kernel.

For the math builtins, see Math in the language reference.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/05_fused_gelu.py

The demo applies the kernel to a 64 by 300 float32 array with scale=0.5, and compares the result with a NumPy reference computed in float64. The output is similar to the following:

max abs error: 4.7683716e-07

The file's docstring runs the demo in the CPU interpreter, with ENCELADUS_INTERPRET=1. Both ways work, and they give errors of the same size. For more information, see Debugging.
