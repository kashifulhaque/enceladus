Row softmax

A softmax over each row of a 2D array, with one program per row. It shows reductions with tl.max and tl.sum, and how a mask's fill value keeps them correct.

What it computes

softmax(x) returns exp(x - max(x)) / sum(exp(x - max(x))) for each row of a 2D array, in the input dtype. It accepts NumPy arrays, enceladus.Tensor objects, PyTorch tensors on the mps device, and MLX arrays. The rows can be strided, including views with a nonzero offset, but the elements within a row must be contiguous.

How it works

  • The grid is (m,): one program for each of the m rows. tl.program_id(0) is the row index.
  • One tile holds a whole row. Tile dimensions must be powers of two, so BLOCK is enceladus.next_power_of_2(n). For the demo's 1,000 columns, that's 1,024.
  • Masked lanes load -inf through other=-float("inf"). That value leaves the row maximum unchanged, and its exponential adds 0 to the sum.
  • The kernel converts the row to float32, subtracts the row maximum for numerical stability, and then divides the exponentials by their sum. tl.store converts the result to the output's dtype.
  • enceladus.element_strides returns the strides in elements for any supported array kind, so the wrapper passes the row stride of the input and the output separately.

For the reduction builtins, see Reductions in the language reference.

Run the example

From the root of a clone of the repository, run the following command:

shell
uv run python examples/02_softmax.py

The demo applies the softmax to a 64 by 1,000 float32 array and compares the result with a NumPy reference computed in float64. The output is similar to the following:

max abs error: 7.450581e-09
