Benchmarks

Enceladus against MLX and PyTorch on one Apple M4 Pro (applegpu_g16s, 16-core GPU, Apple9 family). This GPU isn't Apple10, so matmul2d runs on the regular shader cores.

Throughput relative to MLX

Enceladus faster MLX faster

Each bar shows Enceladus throughput relative to MLX in the same run. Enceladus times use GPU timestamps; MLX times use the wall clock. Values are the minimum over repeated runs; matmul uses 3 interleaved rounds of 10 runs. Matmul rows show the best Enceladus configuration for the shape. The 513³ bar is clipped at +60%. Source: benchmarks/results/2026-09-26-applegpu_g16s-m9.md.

MLX's wall-clock times include about 0.1 ms of launch and synchronization overhead, which inflates the Enceladus lead on short kernels such as the softmax and the 513³ matmul. For how the timing works and how to run the benchmarks, see Methodology.
